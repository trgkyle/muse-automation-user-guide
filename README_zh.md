# 🚀 Muse 自动化 v1.0.0 - Muse.ai AI 自动化 [![English](https://img.shields.io/badge/English-blue)](README.md) [![Tiếng Việt](https://img.shields.io/badge/Tiếng%20Việt-green)](README_vi.md)

**Muse 自动化** 是一款生产力工具，用于在 Muse.ai 上自动化您的创作流程。告别手动逐个输入提示词——实现流程自动化，大规模生成视频和图片。

-----

## ✨ 主要功能

* **🚀 批处理：** 排队数十或数百个提示词，让扩展程序自动提交和生成。
* **🧩 工作流（可视化拖放编辑器）：** 在画布上连接提示词、图片和生成节点——例如先生成图片，再自动用这些图片生成视频。可保存多个工作流，运行单个节点或全部运行，并以文件导入/导出。
* **🎬 文本生成视频自动化：** 从文本描述生成视频。支持带自定义延迟的批处理。
* **🎬 帧图生成视频：** 使用起始帧图片和提示词创建动态视频。
* **🎬 素材生成视频：** 将上传的图片（角色、物体、界面元素）与提示词结合生成视频。
* **🖼️ 文本生成图片批处理：** 每个提示词最多生成 4 张图片，支持宽高比 16:9、9:16、1:1、3:4、4:3。
* **🖼️ 图片生成图片：** 从源图片和提示词生成图片变体。
* **⚙️ 专业控制：**
    * **范围运行：** 只运行列表中的一部分（例如第 5 到第 20 个提示词）。
    * **智能延迟：** 设置提示词之间的随机等待时间（从–到，秒）以管理速率限制。
    * **自动重试：** 生成失败时自动重试（1–20 次）。
    * **自动下载：** 生成完成后自动下载结果。
* **🔗 拼接 / 连续编辑：** 从上一个提示词继续生成视频，或编辑上一个提示词生成的图片。
* **👤 自动添加角色图片：** 根据文件名自动将图片匹配到提示词。
* **📄 导入提示词：** 从 `.txt`、`.xlsx` 或 `.csv` 文件加载提示词。
* **📊 实时队列监控：** 通过侧边面板中的提示词队列和每个提示词的状态监控进度。
* **📂 有序文件管理：** 下载内容按项目分类到文件夹。
* **🌐 多语言支持：** 英语、越南语、中文、韩语、日语、西班牙语。

## 📖 使用指南

### 开始使用

1. **访问 Muse.ai**
   - 打开 [muse.ai](https://muse.ai)
   - 扩展程序在 Muse.ai 页面上运行。在其他页面上，侧边面板会显示 **前往 Muse AI** 按钮。

2. **打开扩展程序**
   - 点击 Chrome 工具栏中的扩展程序图标。建议固定以便访问！

3. **配置批量设置**
   - 在 **控制** 标签页中可设置：
     - **并发提示词数：** 同时运行的提示词数量。
     - **随机延迟：** 处理下一个提示词前的随机等待时间（从–到，0–300 秒）。

4. **选择模式**
   - 可选：**文本生成视频**、**帧图生成视频**、**素材生成视频**、**文本生成图片** 或 **图片生成图片**。

5. **或打开工作流编辑器**
   - 点击控制标签页底部的 **工作流**，用拖放方式搭建多步骤流程（见 [6. 工作流](#6-工作流可视化拖放编辑器)）。

### 1. 文本生成视频模式

1. 选择 **文本生成视频** 模式。
2. 在输入框中输入提示词（每个提示词之间用 **空行** 分隔）。
3. 或点击 **上传** 图标从 `.txt`、`.xlsx` 或 `.csv` 文件导入提示词列表。导入表格时，请选择工作表和列。
4. （可选）在 **每个提示词的视频模式** 中选择 **10秒拼接**，让该提示词的视频与下一个提示词拼接。
5. 设置 **保存到文件夹** 并选择提示词范围（**开始** 到 **结束**）。
6. 点击 **运行** 开始批处理。

**示例提示词：**
```
一个充满霓虹灯的未来派赛博朋克城市，雨水倒映着灯光。
摄像机穿过狭窄的小巷。

一个宁静的日本花园，樱花飘落进池塘。
摄像机缓慢放大观察下方游动的锦鲤。
```

### 2. 帧图生成视频模式

1. 选择 **帧图生成视频** 模式。
2. 点击上传或拖放起始帧图片（PNG、JPG、GIF，每张最大 10MB）。
3. 输入提示词（用空行分隔）。图片按顺序分配给提示词——每个提示词上传一张图片。
4. 点击 **运行**。

### 3. 素材生成视频模式

1. 选择 **素材生成视频** 模式。
2. 上传素材图片（角色、物体、背景）。
3. 输入提示词（用空行分隔）。
4. （可选）开启 **自动添加角色图片**，每个提示词将使用文件名出现在提示词中的图片。例如：`Anna.png` 会被添加到所有包含 "Anna" 的提示词中。
5. 点击 **运行**。

### 4. 文本生成图片模式

1. 选择 **文本生成图片** 模式。
2. 为图片输入详细描述。
3. 选择 **每个提示词的输出数量**（1–4），并在设置标签页中配置所需的 **宽高比**。
4. （可选）在 **每个提示词的图片模式** 中选择 **编辑图片**，让下一个提示词编辑本提示词生成的图片。
5. 点击 **运行**。

### 5. 图片生成图片模式

1. 选择 **图片生成图片** 模式。
2. 上传源图片。
3. 输入图片变体的提示词。也可以开启 **自动添加角色图片**。
4. 点击 **运行**。

### 6. 工作流（可视化拖放编辑器）

工作流是用于多步骤流程的可视化拖放编辑器——例如：先生成几张图片，再用这些图片生成视频，然后用另一个提示词延续每个视频。它在独立窗口中打开，并在您已打开的 muse.ai 标签页上运行。

#### 打开工作流

* 在控制标签页中点击 **工作流**（最下面一排按钮）。
* 已在侧边面板输入提示词或上传图片？将鼠标悬停在 **工作流** 上并点击 **转换为工作流**：提示词、每个提示词的模式和图片都会变成工作流中的节点，可直接运行。

#### 界面

| 区域 | 内容 |
| :--- | :--- |
| **左侧** | **节点**（点击或拖到画布上）和 **我的工作流**（已保存的工作流列表） |
| **中间** | 画布。左上角：撤销/重做、**自动排列**、适应视图、**示例**、清空，以及 **全部运行** 按钮 |
| **右侧** | 概览、实时 **进度**、**问题**（点击可跳到对应节点）、**运行计划** 及所用设置 |

#### 节点

| 节点 | 作用 |
| :--- | :--- |
| **输入提示词** | 一个或多个提示词，用 **空行** 分隔 |
| **上传图片** | 您的图片（可直接把文件拖到节点上）。悬停图片：🔍 放大查看，✕ 删除，拖动角上的手柄可调整顺序。顺序（或排序菜单）决定每个提示词使用哪张图片 |
| **生成图片** | 文本生成图片；连接图片后为图片生成图片。选项：**每个提示词的图片模式**、**每个提示词的最大输入图片数**、**自动添加角色图片** |
| **生成视频** | 文本生成视频；连接图片后为 **帧图生成视频** / **素材生成视频**。选项：**每个提示词的视频模式**、每个提示词的图片数（与侧边面板设置共用）、**自动添加角色图片**（素材生成视频） |

生成节点会根据第一个提示词自动命名（`image_…` / `video_…`）。每行提示词都会显示它将使用的图片，方便运行前检查。

#### 连接节点

从节点右侧的圆形连接点拖出，**放到另一个节点的任意位置**——会自动选择合适的输入口。拖动时，可以连接的节点会高亮。

| 从 | 到 | 含义 |
| :--- | :--- | :--- |
| 输入提示词 | 生成图片 / 生成视频 | 要生成的提示词 |
| 上传图片 | 生成图片 / 生成视频 | 参考图、起始帧或素材 |
| 生成图片 | 生成图片 / 生成视频 | **生成的图片** 作为该节点的输入（图片就绪后才运行） |
| 生成视频 — **最后一帧** 输出 | 生成视频 | 后一个视频 **从前一个视频的最后一帧继续** |
| 生成视频 — **最后一帧** 输出 | 生成图片 | 每个视频的 **最后一帧** 作为输入图片（视频就绪后才运行） |
| 生成视频 — **视频** 输出 🎬 | 生成视频 | **生成的视频作为下一个视频的素材**（素材生成视频；视频就绪后才运行） |

#### 运行

* **全部运行**（左上角，或 `Ctrl/⌘ + Enter`）按正确顺序运行整个工作流：需要生成图片的节点会在图片就绪后自动开始。
* 每个生成节点都有自己的 **运行** 按钮，只运行该节点。在其依赖的节点完成之前按钮不可用（悬停可查看原因）。
* **停止** 取消仍在运行的任务。
* 运行时，连向正在生成的节点的连线会发光并流动，让您看到工作流进行到哪一步。

> ⚠️ **muse.ai 标签页不可见时 Chrome 会暂停它**（例如工作流窗口全屏遮住它时）。点击 **开启后台模式**（工作流中 **全部运行** 按钮下方，或侧边面板中），然后在 Chrome 的对话框中选择 muse.ai 标签页。这会共享 muse.ai 标签页（不会录制或发送到任何地方），让它在其他窗口后面继续生成。绿色的 **后台运行中** 标识表示已开启；点击 ✕ 关闭。

#### 结果

结果直接显示在生成节点中。悬停结果：🔍 放大查看，✕ 删除（橡皮擦按钮清除该节点的全部结果）。悬停时视频自动播放。文件仍会照常下载。

#### 管理工作流

在左侧的 **我的工作流** 中：**新建**、**导入**，以及每个工作流的 **⋯** 菜单——**重命名**（或双击名称）、**复制**、**导出**、**删除**。所有更改都会自动保存。

* **导出** 会下载一个 `.json` 文件。文件开头有 `//` 注释行，描述所有节点、属性和连接方式，因此您可以把文件交给 AI 助手，让它编写新的工作流。导入时会自动去掉这些注释行。
* 用 **导入** 按钮导入文件，或直接 **把 `.json` 文件拖到画布上**。

#### 编辑快捷键

点击顶部栏的 **快捷键**（或按 `?`）查看全部快捷键。

| 操作 | 按键 |
| :--- | :--- |
| 撤销 / 重做 | `Ctrl/⌘ + Z` / `Ctrl/⌘ + Shift + Z` |
| 复制 / 剪切 / 粘贴节点（也可粘贴到其他工作流） | `Ctrl/⌘ + C / X / V` |
| 复制一份所选节点 | `Ctrl/⌘ + D` |
| 全选 / 加选 / 框选 | `Ctrl/⌘ + A` / `Ctrl/⌘ + 点击` / `Shift + 拖动` |
| 自动排列 | `Shift + A` |
| 删除所选 | `Delete` |
| 全部运行 / 后台运行 | `Ctrl/⌘ + Enter` / `Ctrl/⌘ + Shift + Enter` |

## ⚙️ 设置配置

访问 **设置** 标签页自定义体验：

* **默认模式：** 设置默认开启的模式。
* **默认宽高比：** 可选 16:9、9:16、1:1、3:4 或 4:3。
* **默认视频选项：** 每个提示词的默认视频模式（10秒 或 10秒拼接）。
* **默认图片模式选项：** 每个提示词的默认图片模式（新图片 或 编辑图片）。
* **失败时最大重试次数：** 生成失败时的重试次数（1–20）。
* **自动下载质量（视频 / 图片）：** 选择 1080p 视频、1k 图片，或 **不下载**。
* **语言：** 在 English、Tiếng Việt、中文、한국어、日本語、Español 之间切换。
* **下载设置：** 文件保存在 Chrome 的下载文件夹中，并放入项目文件夹。

点击 **保存设置** 应用更改，或点击 **重置为默认值** 恢复默认设置。

## 💡 提示与最佳实践

1. **等待时间：** 若遇速率限制，请增加控制标签页中的 **随机延迟**。
2. **先试运行：** 在运行完整列表前，先运行一小段范围（例如第 1 到第 2 个提示词）。
3. **提示词编写：** 尽量具体。详细提示词带来更好效果。用空行分隔多个提示词。
4. **角色图片：** 用角色名称命名图片文件（例如 `Anna.png`、`Tom.jpg`），以便使用 **自动添加角色图片**。
5. **文件组织：** 下载内容会自动按项目分类到文件夹。保持 **自动更改文件名** 开启，每个文件名将以提示词编号开头。
6. **工作流：** 在 **全部运行** 之前，先用某个生成节点自己的 **运行** 按钮试运行。新手可从 **示例** 开始，并用 **导出** 备份或分享工作流。

## 🔧 故障排除

| 问题 | 解决方案 |
| :--- | :--- |
| **扩展程序未激活** | 确保位于 [muse.ai](https://muse.ai)。如需请刷新页面。 |
| **"Please refresh Muse AI page" 错误** | 刷新 Muse.ai 页面（Ctrl+R、F5）后重试。如果问题仍然存在，请重新安装扩展程序。 |
| **生成错误** | Muse.ai 可能正忙。扩展程序将根据 **失败时最大重试次数** 设置自动重试。 |
| **运行按钮无法点击** | 请添加提示词；使用图片的模式需上传足够的图片（每个提示词一张）。 |
| **运行按钮显示“升级到 Max”** | 您已用完今日的免费次数。请升级到 Max 或明天再试。 |
| **下载无效** | 确保 Chrome 设置中已 **关闭** “在下载前询问每个文件的保存位置”。 |
| **需要登录** | 请确保已登录您的 Muse.ai 账户。 |
| **工作流：结果一直停在“生成中”** | Chrome 暂停了被遮住的 muse.ai 标签页。开启 **开启后台模式**（或 **后台运行**），或保持 muse.ai 标签页可见。 |
| **工作流：某个节点的运行按钮不可用** | 将鼠标悬停在按钮上：先运行它依赖的节点，或修复提示的问题（例如未连接提示词）。 |
| **工作流：“未找到 muse.ai 标签页”** | 在标签页中打开 [muse.ai](https://muse.ai)（顶部栏的绿点表示已连接）。 |

## 🔒 隐私与数据

* **本地处理：** 所有自动化逻辑均在浏览器中本地运行。
* **无数据收集：** 我们不存储或收集您的提示词、图片或账户数据。
* **安全存储：** 设置和工作流仅保存在浏览器的本地存储中。
* **后台模式：** 共享 muse.ai 标签页只是为了让它继续运行，不会录制、保存或发送任何内容。
